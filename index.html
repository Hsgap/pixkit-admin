🔗 1-Line Drop-in Client SDK

Add this script tag into the <head> of any client app (pixkit.site, pixkit-mobile, or Desktop builds) to instantly connect it to this fleet command center: 

<!-- PixKit Remote Fleet SDK -->
<script src="https://pixkit.site/js/pixkit-remote.js"></script>
<script>
  // Automatically listens to Firebase RTDB & enforces maintenance, alerts, flags, and version policies
  PixKitRemote.init({
    platform: window.Capacitor ? 'mobile' : 'web'
  });
</script>
